# Dynamic Base16 AdvShell Theme

A VSCode theme for [AriadnevShell](https://github.com/bavanchun/ariadnev-shell).

## How It Works

1. Install this extension
2. Select one of the "Dynamic Base16 AdvShell" themes in VSCode
3. AriadnevShell automatically updates the theme files when you change themes.

The theme files are located in your VSCode extensions directory and are updated by matugen when generating new colors.

## Themes

- **Dynamic Base16 AdvShell** - Follows your current light/dark mode
- **Dynamic Base16 AdvShell (Dark)** - Always dark variant
- **Dynamic Base16 AdvShell (Light)** - Always light variant
